# Backend

API REST del sistema, desarrollada con **Python + Django + Django REST Framework**, con autenticación por token.

Estructura prevista: una app de Django por módulo (`usuarios`, `sedes`, `proveedores`, `caja`, `ventas`, `pedidos`, `dashboard`). Detalle en [`../docs/03-Arquitectura.md`](../docs/03-Arquitectura.md).

Estado: pendiente. El desarrollo comienza una vez aprobada la etapa de diseño.
